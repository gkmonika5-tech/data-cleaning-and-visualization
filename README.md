# Data Cleaning & Visualization Project

A beginner-friendly Python project that takes a **raw, messy student-performance dataset**, cleans it step by step, analyses it, draws charts and presents everything in an **interactive Streamlit dashboard**.

> **The dataset is synthetic** (computer-generated by `src/generate_dataset.py`). No real student is described. It was built on purpose to contain realistic data-quality problems.

---

## 1. Project introduction

Real-world data is rarely ready to use. Records are missing, entered twice, typed in different styles or contain impossible values such as an age of 150. This project shows the full journey from **raw data → clean data → insights**:

1. Load a messy dataset
2. Clean and preprocess it
3. Explore it with statistics (EDA)
4. Visualize it with charts
5. Present it in an interactive dashboard

## 2. Problem statement

A school collected 526 student records through a survey form. The file contains missing values, duplicate records, impossible values, outliers, inconsistent formats and columns that are not useful. Analysing it directly would give wrong or misleading results. The problem is to **convert this raw data into clean, reliable information and discover what factors are linked with student performance.**

## 3. Objectives

- Detect and fix missing values, duplicates, outliers, inconsistent formats and unnecessary columns
- Save a clean dataset (`dataset/cleaned_data.csv`)
- Perform exploratory data analysis (descriptive statistics, mean/median/mode, min/max, correlation)
- Create six required charts (bar, pie, histogram, box plot, scatter plot, heatmap) plus a before/after chart
- Build an interactive dashboard with filters
- Test the whole project automatically

## 5. Dataset description

`dataset/raw_data.csv` — **526 rows × 18 columns** (synthetic).

| Column | Meaning | Data-quality problem planted in the raw file |
|---|---|---|
| `student_id` | Unique ID (STU1001 …) | 26 repeated IDs (duplicates) |
| `student_name` | Synthetic name | Unnecessary (personal identifier) |
| `gender` | Male / Female | Written 11 different ways (`M`, `male`, `FEMALE` …); ~5% missing |
| `age` | Age in years | Impossible values (150, 5, -3); ~5% missing |
| `school_type` | Government / Aided / Private | Mixed capital letters and extra spaces |
| `parental_education` | Parent's education level | Mixed capital letters; `N/A`; ~5% missing |
| `internet_access` | Internet at home (Yes/No) | `Y`, `n`, `YES` …; ~5% missing |
| `extra_classes` | Attends tuition (Yes/No) | `Y`, `n`, `YES` … |
| `study_hours_per_week` | Self-study hours | Outliers (85–150 h/week); `-`; ~5% missing |
| `attendance_percent` | Attendance % | Stored as text (`87.5%`) in 60 rows; values above 100; ~5% missing |
| `previous_score` | Previous exam % | ~5% missing |
| `math_score`, `science_score`, `english_score` | Marks out of 100 | Impossible values (999, -20, 200); very low outliers; `?`; ~5% missing |
| `exam_date` | Date of exam | Five different date styles |
| `data_entry_operator` | Who typed the record | Unnecessary |
| `internal_remarks` | Free-text note | Unnecessary, 44% empty |
| `record_source` | Source form name | Unnecessary (same value in every row) |

Three columns are **added** during cleaning: `average_score` (mean of the 3 subjects), `grade` (A ≥ 75, B 60–74, C 50–59, D 40–49, F < 40) and `study_level` (Low < 10 h, Medium 10–19 h, High ≥ 20 h).

## 6. Data cleaning techniques (`src/data_cleaning.py`)

| Step | What is done | Technique |
|---|---|---|
| 1 | Load raw dataset | `pd.read_csv` (`?`, `-` read as missing) |
| 2 | Display first five rows | `df.head()` |
| 3 | Rows and columns | `df.shape` |
| 4 | Identify missing values | `df.isna().sum()` + percentage table |
| 6a | Remove exact duplicate rows | `drop_duplicates()` (20 removed) |
| 8 | Correct inconsistent formats | Remove `%`, map spellings to one label, parse 5 date styles, turn impossible values into missing |
| 6b | Remove re-typed duplicates | `drop_duplicates(subset="student_id")` (6 removed) |
| 5 | Handle missing values | **Median** for numbers, **mode** for categories |
| 7 | Handle outliers | **IQR rule** (Q1 − 1.5·IQR, Q3 + 1.5·IQR); extreme values are **capped** |
| 9 | Remove unnecessary columns | Drop 4 columns |
| 10 | Save cleaned data | `to_csv` → `dataset/cleaned_data.csv` |

*Why not in numerical order?* Some steps need others first (formats must be tidy before duplicates and missing values can be judged). The code prints each step with its brief number.

*Why median, not mean?* The median is not pulled by extreme values. *Why cap instead of delete outliers?* Deleting would throw away the rest of a student's record.

## 7. Data analysis methods (`src/data_analysis.py`)

- **Descriptive statistics** – count, mean, standard deviation, min, quartiles, max
- **Mean, median, mode** – three measures of the centre
- **Minimum, maximum, range**
- **Correlation** (Pearson r, −1 to +1) between all numeric columns
- **Group comparisons** – average score by school type, parental education, extra classes, internet access, gender, study level
- **Observations** – sentences generated from the real numbers

> Note: for most columns the *mode equals the median*. That is a side effect of filling about 25 missing cells with the median — the filled value becomes the most frequent value.

## 10. How to run the project (step by step, in VS Code)

**Before you start:** install Python 3.9 or newer from https://www.python.org (on Windows tick *"Add Python to PATH"*) and install VS Code with its **Python** extension.

### Step 1 – Open the project
1. Unzip `Data_Cleaning_Visualization.zip`.
2. In VS Code choose **File → Open Folder…** and select the `Data_Cleaning_Visualization` folder.
3. Open the terminal: **Terminal → New Terminal**.

### Step 2 – Create a virtual environment (recommended)
Windows:
```
python -m venv venv
venv\Scripts\activate
```
If PowerShell blocks the script, run `Set-ExecutionPolicy -Scope Process Bypass` first, then activate again.

macOS / Linux:
```
python3 -m venv venv
source venv/bin/activate
```
Press **Ctrl+Shift+P → "Python: Select Interpreter"** and choose the interpreter inside `venv`.

### Step 3 – Install the libraries
```
pip install -r requirements.txt
```

### Step 4 – Run the complete pipeline
```
python main.py
```
This cleans the data, prints every step, runs the analysis, saves the graphs and writes `outputs/run_log.txt`. (Use `python main.py --regenerate` to create a fresh raw dataset first.)

### Step 5 – Start the dashboard
```
streamlit run app.py
```
Your browser opens `http://localhost:8501`. Press **Ctrl+C** in the terminal to stop it.

### Step 6 – Run the tests
```
python -m pytest -v
```

You can also run a single stage: `python -m src.data_cleaning`, `python -m src.data_analysis`, `python -m src.data_visualization`.

### Troubleshooting
| Problem | Fix |
|---|---|
| `'streamlit' is not recognized` | Activate the virtual environment, or run `python -m streamlit run app.py` |
| `ModuleNotFoundError: No module named 'src'` | Run commands from inside the `Data_Cleaning_Visualization` folder |
| `ModuleNotFoundError: pandas` (etc.) | Run `pip install -r requirements.txt` in the activated environment |
| Port already in use | `streamlit run app.py --server.port 8502` |

## 12. Key findings

- Weekly study hours has the strongest link with the average score (r = 0.71), then previous exam score (r = 0.58).
- Average score by study level: Low 48.9, Medium 56.2, High 66.9.
- Extra classes (+3.1 marks), internet access (+3.0) and private schools (61.2 vs 57.2 government) are linked with higher scores.
- Age, attendance and gender show almost no relationship with the average score in this dataset.

## 13. Conclusion

The project shows that cleaning is essential: 526 messy rows became 500 reliable records with no missing values, duplicates or impossible values, and only then could the data be analysed and visualized meaningfully. Because the data is synthetic, the relationships illustrate the method and are not conclusions about real students. Correlation also does not prove cause and effect.

**Limitations and future work:** median filling and capping reduce natural variation (visible as vertical stripes in the scatter plot); future versions could use a real dataset, smarter imputation (for example by group), regression/machine-learning models and deployment of the dashboard online.
